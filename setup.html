環境設定紀錄

從零開始：在 Windows 上用 Claude Code 裝好工具、登入 GitHub，再把網站架上 GitHub Pages。(給孩子)

1. 語言偏好

在使用者層級的 CLAUDE.md 寫下「一律使用繁體中文回答，專有名詞可保留英文」。Claude Code 每次開對話都會讀這個檔案，所以不管在哪個專案都適用。

2. 安裝 Claude in Chrome

  1. 用 Chrome 打開 claude.ai/chrome，從 Chrome Web Store 安裝發行者為 Anthropic 的 extension。
  2. 點工具列上的 Claude 圖示，用同一個 Claude 帳號登入。
  3. 回到 Claude Code，確認瀏覽器已連線。

3. 安裝開發工具

由 Claude 在背景用 winget 安裝，全部使用預設選項：

安裝完後要開新的終端機視窗，PATH 才會更新，node、git、gh、code 這些指令才找得到。

4. GitHub 授權（device flow）

  1. Claude 先用 gh auth status 檢查，確認還沒登入。
  2. 在背景執行 gh auth login --web，取得一次性驗證碼。
  3. Claude 用 Claude in Chrome 打開 github.com/login/device，把驗證碼填好。
  4. 本人確認帳號後，按 Continue 和 Authorize。
  5. 執行 gh auth setup-git，讓 Git 直接用 GitHub CLI 的登入資訊，之後 push 不用再輸入密碼。

5. 架站：GitHub Pages

  1. 把對話整理成這幾頁純 HTML + CSS 的靜態網站，不需要任何建置工具。
  2. 從 Unsplash 找免費授權的圖片放在每頁的 HERO 區，等比例縮放，寬度不超過內文區，並標註攝影師。
  3. 用 gh repo create 建立公開 repo，並 push 程式碼。
  4. 用 GitHub API 開啟 GitHub Pages，來源設為 main branch 的根目錄。
  5. 用 Claude in Chrome 打開網址，逐頁檢查。

結論

整個過程本人只需要做三件事：安裝 Chrome extension、在 GitHub 按 Authorize、確認要公開網站。其他安裝、寫程式、上傳、檢查都由 Claude 在背景完成。
