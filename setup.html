環境設定紀錄

從零開始：在 Windows 上用 Claude Code 裝好工具、登入 GitHub，再把網站架上 GitHub Pages。(給孩子)

寫在前面

你現在看的這整個網站，爸爸一行程式都沒有自己寫。

爸爸只是用中文跟 AI 說「我想要什麼」，AI 就自己去裝軟體、上網找資料、寫網頁、找圖片、把網站放上網路，最後還打開瀏覽器一頁一頁檢查有沒有壞掉。

這種會自己動手做事的 AI，叫做 AI agent。這一頁記錄了整個過程，看完你也可以自己試試看。

AI agent 是什麼？

一般的聊天 AI

你問問題，它回答。像一個很會講解的老師，但只會動嘴，事情還是要你自己做。

AI agent

你交代任務，它會拿工具自己做：打指令、開檔案、寫程式、操作瀏覽器，做完還會檢查、回報結果。

用三角洲來比喻：AI agent 就像你帶的一個幹員（agent 的英文本來就是「特工、幹員」）。你是隊長，負責下命令、做決定；幹員有自己的裝備和技能，收到命令就自己出任務。好的幹員遇到危險的決定，還會先回頭問隊長。

任務紀錄

下面是爸爸實際對 AI 說的話（有些經過簡化），以及 AI 做了什麼。

MISSION 01

設定規則

以後都用繁體中文回答，專有名詞可以保留英文。

把這條規則寫進一個設定檔，以後每次對話都會自動遵守。

AI 可以「記住」你的偏好，只要你把規則講清楚。

MISSION 02

安裝 Claude in Chrome

幫我安裝 Claude in Chrome。

說明安裝步驟，但請爸爸自己按安裝；裝好後確認瀏覽器已經連上。

安裝瀏覽器擴充功能這種事，AI 會讓人自己來做。

MISSION 03

安裝軟體、登入 GitHub

檢查並安裝 VS Code、Node.js、Git、GitHub CLI，缺什麼就裝什麼。然後完成 GitHub 授權，驗證碼幫我填好，我來登入和按 Authorize。

在背景一口氣裝好四個軟體，開啟 GitHub 授權網頁、填好驗證碼，停下來等爸爸按 Authorize，再確認登入成功。

登入、授權這種「鑰匙」等級的動作，一定由人來按，AI 只負責準備好。

MISSION 04

把對話變成網站

把我們的對話整理成網站，放到 GitHub（設成公開），用 GitHub Pages 做成公開網址，再用 Chrome 檢查每一頁。

寫好四個網頁，準備上傳時被安全機制擋下來：要公開到網路上的東西，必須爸爸再確認一次。爸爸同意後才上傳、開啟網站，並逐頁檢查。

公開到網路上的東西收不回來，所以 AI agent 會先停下來問。

MISSION 05

加圖片、整理標題

去網路上找圖放在適當的地方；標題、副標、結論要清楚；圖片放在 HERO 區，等比例縮放，寬度不超過文字區。

到 Unsplash 找免費授權的照片，每頁放一張並標註攝影師；每頁加上清楚的結論區塊；用程式量出圖片寬度剛好等於文字區。

網路上的圖不能隨便用，要找可以合法使用的，並寫出是誰拍的。

MISSION 06

幹員介紹和按鍵配置

請增加幹員介紹（附圖）和按鍵配置建議。

上網查了好幾個攻略網站整理幹員技能。因為遊戲官方的角色圖有版權，AI 改成自己畫每個幹員的示意圖。不確定的中文名字，就老實只寫英文。

好的 AI agent 不確定的事會說不確定，而不是亂編。

MISSION 07

改成三角洲風格

網頁以三角洲風格設計。

把整個網站改成深色戰術介面：螢光綠、切角面板、瞄準角框。

黑底情況下，灰階字體和部分圖有點不夠清晰，建議增加對比。

把字調亮、用程式算出每種文字的「對比度」確認夠清楚，太暗的圖也換掉。

第一次做不完美很正常。看完結果再給意見，AI 就會改得更好。

MISSION 08

設計網站小圖示

設計 3 個 favicon 讓我挑選。

畫了三種設計，並模擬放在瀏覽器分頁上的樣子；爸爸選了 A「三角準星」後，做成三種尺寸放上網站。

可以請 AI 多給幾個選項，再由你來決定。決定權在你。

MISSION 09

職業賽事和經濟系統

Delta 是否有職業競賽？……好喔，麻煩你了。

查了新聞和賽事網站，整理成「職業賽事」頁；之後又把護甲、物資、特勤處的說明整理成「經濟系統」頁。

先問問題，覺得有用再請 AI 整理下來，網站就這樣一頁一頁長大。

AI agent 的安全守則

這次過程中，AI 有幾件事一定會停下來，或交給爸爸自己做：

  • 登入和授權：密碼、按 Authorize 這種事由人來做。
  • 公開到網路上：上傳公開網站前，會再確認一次。
  • 不用有版權的東西：遊戲官方美術不能直接拿來用，所以自己畫或找免費授權的圖。
  • 不洩漏個人資料：網站上沒有放爸爸的本名、email 或密碼。
  • 不確定就說不確定：查不到的資料會老實寫「請以官方公告為準」。

這些也是你自己用 AI 時要記住的事。

換你試試看

找爸爸一起，打開 Claude Code，試試下面的挑戰。不用會寫程式，只要把想法講清楚：

  1. 新手任務：「在幹員介紹頁加一段，介紹我最常用的幹員，以及我為什麼喜歡他。」
  2. 進階任務：「幫我做一個小測驗頁，考爸爸 5 題三角洲的問題，答完會顯示分數。」
  3. 高手任務：「幫我做一個新頁面，整理我最常玩的地圖和撤離點。」做完記得請 AI 用瀏覽器檢查一遍。

小秘訣：說清楚「要做什麼、放在哪裡、做完怎麼檢查」，AI 就會做得很好。結果不滿意，就像這次爸爸一樣，直接說哪裡要改。

給大人看的技術細節
  • 語言偏好寫在使用者層級的 CLAUDE.md，所有專案都適用。
  • 用 winget 安裝：VS Code 1.143.1、Node.js LTS v26.13.0（npm 11.20.0）、Git 2.56.0、GitHub CLI 2.103.3。安裝後要開新的終端機視窗，PATH 才會更新。
  • GitHub 登入用 device flow：gh auth login --web，再用 gh auth setup-git 讓 Git 使用 GitHub CLI 的憑證。
  • 網站是純 HTML + CSS 的靜態網站，用 gh repo create 建立公開 repo，透過 GitHub API 開啟 GitHub Pages（main branch 根目錄）。
  • 圖片來自 Unsplash 免費授權；favicon 以 SVG 為主，另有 32px PNG 和 180px apple-touch-icon。

結論

這個網站是爸爸當隊長、AI 當幹員一起完成的。爸爸負責想法和做決定，AI 負責動手做和檢查。你不用先學會寫程式，只要學會把事情講清楚，就能開始指揮自己的 AI agent。
