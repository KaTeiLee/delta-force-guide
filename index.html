從 CS 到三角洲

十年 CS 老玩家被孩子拉進三角洲行動（Delta Force），從被虐開始的升級筆記。

這個網站在講什麼

一位打了十多年 CS（現在是 CS2）的中等程度玩家，被孩子拉進三角洲，初期一直被打。這裡整理了我和 Claude 的對話，給同樣處境的玩家參考。

這個網站是怎麼做出來的：安裝工具、登入 GitHub、架上 GitHub Pages。

結論

CS 的槍法和判斷到三角洲依然值錢。先讀入門到進階搞懂規則差異，再用靈敏度換算把手感帶過去，就能從被虐的那個，變成隊友倚重的那個。
